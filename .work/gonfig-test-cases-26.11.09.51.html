How this collection was built

  • Unit boundary: a Go file with the same receiver. Helpers in the same file are not separate units.
  • Stack trace first: every method's call footprint inside the module was traced before deriving cases.
  • Contract per method: preconditions, postconditions, and the type invariants that must hold before and after the call.
  • Temporary invariant breaks: intermediate states where a method makes an invariant false (for example, Set replacing a scalar to open a path, or Merge copying a source before taking the receiver lock) are called out and tested.
  • No duplicate hidden testing: getPath, setPath, deletePath, mergeMaps, and ensureMapInitialized are asserted through their public callers only. DeepCopyMap is public, so it has its own pack.
  • Pre/post checked once or omitted: trivial always-true preconditions are stated but not turned into standalone tests.
